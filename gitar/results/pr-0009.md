Adds the Now screen with status pill, placement flow, reroute banner and stream handling, but changes are requested: Now's cleanup is lost if the user navigates away while the initial refresh is pending, leaving intervals, handlers and a possible automatic placement request running after the screen is gone. Fix by building the cleanup before awaiting refresh, tracking a disposed flag, and not awaiting the first refresh before returning.

<details>
<summary>⚠️ <b>Bug:</b> Now's cleanup is lost if the user leaves while refresh() is pending</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/9/files#diff-55599e1384b0aa31539caf3a5f4d614e3564dcff0ca95eb9f6999d9f9be3a964R222-R236">frontend/static/js/screens/now.js:222-236</a></kbd>

`render` sets up the stream subscriptions and both `setInterval` polls, then runs `await refresh()` (a network call) and an automatic `findMeATalk()` before it returns the cleanup function. The router in `main.js` only stores the cleanup once `screen.render` resolves (`cleanup = await screen.render(...)`). If the user leaves Now before `refresh()` finishes, the router has no cleanup to call yet and renders the next screen.

When the old Now render finally resolves, three things go wrong:
1. Its cleanup overwrites the new screen's cleanup, so the new screen's resources are never released.
2. Now's intervals and handlers keep firing and painting into a detached `region` until some later navigation.
3. The automatic `POST /api/placements` can still go out after the person has left.

Slow networks and the backend being down make this more likely. Fix: build the cleanup first, track a `disposed` flag, and don't `await` the first refresh before returning.

<details>
<summary>Return cleanup right away and skip the follow-up work once the screen is disposed.</summary>

````
let disposed = false;
paint();
refresh().then(() => {
  if (disposed) return;
  if (!placement && !autoRequested) {
    autoRequested = true;
    findMeATalk();
  }
});

return () => {
  disposed = true;
  unsubs.forEach((u) => u());
  clearInterval(poll);
  clearInterval(fastPoll);
};
````
