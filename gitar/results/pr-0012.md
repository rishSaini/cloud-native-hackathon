<summary>⚠️ <b>Bug:</b> "Fixed" line comes back every 60 s for resolved incidents</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/12/files#diff-8376d7a6d890da5ba264124f0da793d2d4d621c103171c33050f6b7c60c1b195R145-R154">frontend/static/js/board/board.js:145-154</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/12/files#diff-61f21c0aab67533cf5c0acb93a2255dea4f5af5570eab8579f5677afe2769a8cR226-R234">frontend/static/js/mock-api.js:226-234</a></kbd>

`trackFixed` drops a `fixedSeen` entry once it is older than `FIXED_SHOW_MS`. On the next pass it adds the entry straight back, because the room's incident still has `state === "resolved"` and the room is no longer in `fixedSeen`. The incident does stay that way: in `mock-api.js` `resolveIncident` only sets `room.incident.state = "resolved"` and leaves `room.incident` in place. So after an incident is resolved, the card shows "Fixed HH:MM", fades, and then reappears at full opacity, and this repeats about once a minute for the rest of the event. To fix it, remember which incidents have already been shown (for example by incident id, or by `fixedAt`) separately from the display timer, and only add a room again when a new incident is resolved.

<details>
<summary>Key on the incident so each resolution shows once</summary>

````
const fixedShown = new Set(); // incident ids already shown
function trackFixed() {
  for (const room of board.rooms || []) {
    const inc = room.incident;
    const key = inc && (inc.id || `${room.id}|${inc.fixedAt}`);
    if (inc && inc.state === "resolved" && !fixedShown.has(key)) {
      fixedShown.add(key);
      fixedSeen.set(room.id, { at: Date.now(), fixedAt: inc.fixedAt || formatTime(new Date()) });
    }
    if (inc && inc.state !== "resolved") fixedSeen.delete(room.id);
  }
  for (const [id, f] of fixedSeen) if (Date.now() - f.at > FIXED_SHOW_MS) fixedSeen.delete(id);
}
````

Only `refresh()` hides the pill. Suppose a fetch fails and then the stream connects. Board updates now arrive through `subscribe("board", …)` → `setBoard`, which never sets `pill.hidden`, and the poller stops calling `refresh()` because `isLive()` is true. The projector then shows "Reconnecting" while live data is updating the screen. To fix it, set `pill.hidden = true` inside `setBoard` whenever valid data is received.

<details>
<summary>Fix</summary>

````
function setBoard(next) {
  const data = next?.board ?? next;
  if (!data?.rooms) return;
  board = data;
  pill.hidden = true;
  paint();
}
````
