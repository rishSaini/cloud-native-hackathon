`data?.group ?? data` falls back to the whole response when `data.group` is `null`. So when the server returns `{ group: null }` (the person has no group yet), the method returns the wrapper object `{ group: null }`. `setGroup` then treats that object as a group, and `groupView()` calls `group.members.filter(...)` on `undefined`, which throws a TypeError. That leaves the screen broken for anyone who has no group. The fix is to check whether the `group` key exists rather than whether its value is nullish.

<details>
<summary>Unwrap `group` whenever the key exists, including when its value is null</summary>

````
currentGroup: withFallback("currentGroup", async () => {
  const data = await request("GET", "/api/groups/current");
  return data && typeof data === "object" && "group" in data ? data.group : (data ?? null);
}),
````

<summary>⚠️ <b>Bug:</b> Countdown ticker repaints every second once no no-show notice shows</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/15/files#diff-ae3be8f3d8252cc6e3777f3b905ea473b9310ae4eda6a459796ccf9c27ae406bR150">frontend/static/js/screens/group.js:150</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/15/files#diff-ae3be8f3d8252cc6e3777f3b905ea473b9310ae4eda6a459796ccf9c27ae406bR171">frontend/static/js/screens/group.js:171</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/15/files#diff-ae3be8f3d8252cc6e3777f3b905ea473b9310ae4eda6a459796ccf9c27ae406bR229-R236">frontend/static/js/screens/group.js:229-236</a></kbd>

The third branch of the 1s ticker repaints whenever more than 3 minutes have passed since the break started and there is no `.notice` element on the page. `groupView` only renders that notice when `missing.length > 0`. Once every member has checked in (or there are no members), the notice never appears, so `paint()` runs every second for the rest of the session. Each repaint rebuilds the whole region. Any member menu that was open, including its Block and Report buttons, gets hidden again, and focus on those buttons is lost because they have no `data-key`. The `role=status` nodes are also recreated every second. The fix is to repaint only once, when the no-show threshold is crossed.

<details>
<summary>Repaint once when the no-show threshold is crossed. Reset `noShowPainted` in setGroup when a new group arrives.</summary>

````
let noShowPainted = false;
const tick = setInterval(() => {
  if (!group) return;
  const el = region.querySelector("[data-countdown]");
  const text = countdownText(group.startsAt);
  if (el && text) el.textContent = text;
  else if (el && !text) paint(); // the break started
  else if (!noShowPainted && Date.parse(group.startsAt) + NO_SHOW_MS < Date.now()) { noShowPainted = true; paint(); }
}, 1000);
````
