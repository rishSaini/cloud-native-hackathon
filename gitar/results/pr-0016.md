<kbd>🔴 High risk</kbd> · The new es\_setup.py --reset deletes Affinity indices and the room-report stream, which could erase stored attendee interests and room reports.

Adds `POST /api/rooms/{room_id}/reports` to the `room-reports` data stream, storing only attendee hashes, with a 2-minute per-reporter, room and signal limit enforced by an ES count check. Changes are requested before merge for two open findings: the rate limit is check-then-write, so concurrent duplicates can both be stored and return 202 instead of 429, and the new span `room.report.received` and counter `affinity_room_reports_total` lack the required `talkscout.` or `search.` prefix.

<details>
<summary>⚠️ <b>Bug:</b> Rate limit is check-then-write and lets concurrent duplicates through</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/16/files#diff-ff5c833d7cc6fbd3e29fb7c3bd8d8adbc2c6f7c5201e6ed61f32ebf55d33bcfbR27-R41">backend/app/reports/ingest.py:27-41</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/16/files#diff-ecf155e1911450cf410222dcfd2fa44a6ef93eb98935f305e6468ca0ff61ea83R47-R52">backend/app/reports/routes.py:47-52</a></kbd>

`recently_reported` runs an ES `count`, and only afterwards does `record_report` index the document. Two requests that arrive together (a double tap, a client retry, or the same report landing on both replicas) both see count 0, both get stored, and both return 202. So the "one report per reporter, room and signal every 2 minutes" rule, which this PR describes as safe across replicas, fails in exactly the concurrent case it is meant to handle. `refresh="wait_for"` only helps requests that arrive after the write has finished. A fix is to make the write itself enforce the limit: give each report a deterministic `_id`, such as a hash of reporter, room, signal and a 2-minute time bucket, and index it with `op_type=create`. Data streams accept custom IDs with create, so a `ConflictError` (409) can then become the 429.

<details>
<summary>Make the indexed document ID enforce the window, and map a conflict to 429</summary>

````
bucket = int(time.time() // 120)
doc_id = hashlib.sha256(f"{reporter_hash}:{room}:{signal}:{bucket}".encode()).hexdigest()
try:
    es.index(index=m.ROOM_REPORTS, id=doc_id, document=doc, op_type="create", refresh="wait_for")
except ConflictError:
    raise RateLimited()
````
