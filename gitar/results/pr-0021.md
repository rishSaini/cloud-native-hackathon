Adds a comfort dial (High energy, Steady, Low sensory, Recharging) to the Card screen and a compact version on Now, saved via `PUT /api/card`. Changes requested before merge: editing the card after using the dial reverts `comfort` because `card.js` uses a stale local copy, an unrecognised `comfort` value crashes the Card and Now screens in `comfort.js`, and the `calmFromDial` flag is lost on reload so calm mode may never turn back off.

<details>
<summary>⚠️ <b>Bug:</b> Editing the card after using the dial reverts comfort</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/21/files#diff-e0067522ee59c198ae92cb1b94edfb2b2a6579a49e3463e00ea566923b432416R43">frontend/static/js/screens/card.js:43</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/21/files#diff-35465178cf8e6e4e3b2d28b557b1db55093c8e96491f818ab7ef4375d8806001R50-R55">frontend/static/js/comfort.js:50-55</a></kbd>

In `card.js`, `render()` reads `card` from `loadMe()` once. The dial saves through `saveMyCard`, which updates the store's card but not this local `card` variable. If you then tap Edit, `edit()` builds `draft = { ...card }` from that stale copy, so saving the edit sends `PUT /api/card` with the old `comfort` value (or none), and the dial setting is silently lost. The flip card preview also stays stale. Fix: in `edit()` (and `view()`), read from `currentCard()`, or pass an `onChange` to the dial that updates the local `card`.

<details>
<summary>Keep the screen's local card in sync with the dial so Edit/Save keeps comfort.</summary>

````
comfortDial({ idPrefix: "card-comfort", onChange: (v) => { card = { ...card, comfort: v }; } }),
````

</details>

`comfortOf` returns any truthy `card.comfort` as-is. If the backend stores or returns a value outside high/steady/low/recharge (this field is new and the backend hasn't confirmed it yet), `COMFORT.find` returns undefined, `describe()` throws on `c.detail`, and both Card and Now fail to render. Fix: fall back to `steady` when the value isn't a known id.

<details>
<summary>Fix</summary>

````
export const comfortOf = (card) => (COMFORT.some((c) => c.id === card?.comfort) ? card.comfort : "steady");
````

<details>
<summary>💡 <b>Edge Case:</b> <code>calmFromDial</code> is lost on reload, so calm mode is never turned back off</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/21/files#diff-35465178cf8e6e4e3b2d28b557b1db55093c8e96491f818ab7ef4375d8806001R20-R26">frontend/static/js/comfort.js:20-26</a></kbd>

Calm mode is saved in localStorage, but `calmFromDial` is a module variable that resets to false on every page load. Suppose you pick Low sensory (calm turns on), reload, then pick Steady or Recharging: calm mode stays on, which contradicts the promised behaviour that the dial turns it off again. Fix: store this flag alongside the prefs, for example `setPrefs({ calm: true, calmFromDial: true })`, and read it back from `getPrefs()`.
