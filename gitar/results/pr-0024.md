Adds the controller skeleton with a level-triggered reconcile loop, RBAC, and a Deployment manifest for the kwok placement work. One open issue needs attention before merge: `/healthz` returns 200 indefinitely if no reconcile pass ever succeeds, for example when the API server is unreachable or the ClusterRoleBinding returns 403, so the probes never fail. The fix is to bound the startup grace window by a `started` timestamp and add a test for the stale/never-passed 503 path.

The handler treats `controller.passes == 0` as healthy. `passes` only goes up after `list_node`/`list_namespaced_pod` succeed in `run_once`. If those calls fail from startup, every pass raises before the increment, `passes` stays 0 and `/healthz` keeps answering 200. That happens when the API server can't be reached, when the ClusterRoleBinding is missing or names the wrong namespace (403 Forbidden), or when the kubeconfig is bad. In each case the liveness and readiness probes never fail and the pod looks Ready while doing nothing, which is the failure this endpoint is meant to catch. The test only covers the fresh-pass case. Fix: allow `passes == 0` only during a startup grace window (for example, measured from a `started` timestamp set in `__init__`), and add a test for the stale/never-passed 503 path.

def healthy(self) -> bool:
    limit = 3 * self.resync + 30
    ref = self.last_pass if self.last_pass > 0 else self.started
    return time.monotonic() - ref < limit
