<kbd>🔴 High risk</kbd> · Adds signed-session authentication and encrypted attendee-card storage, changing who can access personal profiles; flaws could expose sensitive attendee data.

Adds `POST /api/attendees` with signed HttpOnly session cookies, AES-256-GCM encrypted cards at `PUT/GET/DELETE /api/card`, and `upsert_person`/`delete_person` consent sync. Blocked by one open critical finding: when `SESSION_SIGNING_KEY` or `CARD_ENCRYPTION_KEY` is missing from `app-credentials`, `backend/app/auth.py` and `backend/app/cards/crypto.py` fall back to public dev keys committed in the repo, letting anyone forge sessions and decrypt another attendee's card. Fail startup or the affected routes when these keys are absent outside local development.

`app-credentials` is mounted with `optional: true` (deploy/deployment.yaml:28-31, deploy/controller.yaml:36-39). If the Secret is missing, or exists without `SESSION_SIGNING_KEY`/`CARD_ENCRYPTION_KEY`, `_signing_key()` uses `affinity-dev-signing-key` and `_key()` uses `affinity-dev-card-key-32-bytes!!`. Both strings are committed in this public repo. The session fallback logs nothing, and the card fallback only logs a warning on each call.

This PR makes `current_attendee_id` real, so the risk is no longer theoretical. Anyone can compute `<id>.<HMAC(dev key, 'session:'+id)>` for any attendee and call `GET /api/card` to read that person's name, pronouns, how-to-talk text and access needs. Attendee IDs aren't secret: they show up in Pod names (`attendee-<id>-<slot>`) and in `displayId`. The ciphertext in Postgres is also only protected by the public key. Telemetry `attendee_hash` values can be reversed the same way.

Fix: refuse to start (or fail these routes) when the keys are missing outside local development. For example, gate the dev keys behind an explicit `AFFINITY_DEV=1` flag and raise otherwise.

def _key() -> bytes:
    raw = os.getenv("CARD_ENCRYPTION_KEY")
    if not raw:
        if os.getenv("AFFINITY_DEV") != "1":
            raise RuntimeError("CARD_ENCRYPTION_KEY is not set")
        return _DEV_KEY
    key = base64.b64decode(raw)
    if len(key) != 32:
        raise RuntimeError("CARD_ENCRYPTION_KEY must be 32 bytes, base64-encoded")
    return key

        key = _DEV_SIGNING_KEY
    return key.encode()
