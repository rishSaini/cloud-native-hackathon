<summary>💡 <b>Bug:</b> Wake lock can be acquired after Show screen cleanup and never released</summary>

`requestLock()` is async. If the person taps Done before `navigator.wakeLock.request` resolves, or while a request started by `visibilitychange` is still pending, cleanup runs while `lock` is still null. The request then resolves and assigns a sentinel that nothing releases, so the screen stays awake after the person has left Show. To fix it, keep a `disposed` flag. Once cleanup has run, release any lock that resolves late instead of storing it.


**Release a lock that resolves after cleanup:**
````
let lock = null, disposed = false;
const requestLock = async () => {
  try {
    const l = await navigator.wakeLock?.request("screen");
    if (disposed) l?.release(); else lock = l;
  } catch { lock = null; }
};
// ...
return () => {
  disposed = true;
  document.removeEventListener("visibilitychange", onVisible);
  try { lock?.release(); } catch { /* already released */ }
};
````
