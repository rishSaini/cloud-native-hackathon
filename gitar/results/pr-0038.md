<details>
<summary>⚠️ <b>Bug:</b> Import sort flips reconciler order so rooms runs after placement</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/38/files#diff-fb351733f7dac9664c78eccbb53b846bd933d2441842cb25ac71589c336f783aR6-R12">backend/app/controller/__main__.py:6-12</a></kbd>

`@register` adds reconcilers to `_REGISTRY` in import order, and `Controller` runs them in that order (loop.py:25-29, 47). The old separate imports, with their `# noqa: I001` comments, put `rooms` first ("taints before placing") and `reroute` after `placement`. The new grouped import is sorted alphabetically, so the order is now cleanup, groups, placement, reroute, rooms. `rooms` runs last, so on each pass Pods get created against Nodes whose closed/full taints and seat labels haven't been updated yet. Groups and cleanup also move ahead of placement. The `I001` noqa comments now sit on the wrong lines and no longer keep the order. Put back the separate, ordered import statements and suppress isort for that block.

<details>

from app.controller import rooms  # noqa: F401, I001  (registers first: taints before placing)
