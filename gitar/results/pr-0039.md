<summary>💡 <b>Bug:</b> Mock felt-heard counters ignore demo reset and override finale value</summary>

`snapshot()` uses `heardYes/heardTotal` whenever `heardTotal > 0`, so any reflection made during a rehearsal hides the `state.feltHeard = 94` that `demo.finale()` sets. Also, `demo.reset()` only rebuilds `state`. The module-level `heardYes`, `heardTotal` and `myGrowth` keep their values, so the board still shows the old percentage after a reset. Clear these counters (and `myGrowth`) in `reset()`, and give the explicit rehearsal value priority.


**Fix:**
````
feltHeard: state.feltHeard ?? (heardTotal ? Math.round((heardYes / heardTotal) * 100) : null),
// and in reset():
heardYes = 0; heardTotal = 0; Object.assign(myGrowth, { level: 1, reflections: [], startedOnOwn: 0, wins: [] });
````
