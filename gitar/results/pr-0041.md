<summary>⚠️ <b>Security:</b> Staff token goes in the URL query string and lands in logs/traces</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/41/files#diff-40706f38b703cef839b8e29b85c7eb580111a9f5dd93989b9010f18c7b812e49R32-R38">backend/app/incidents/routes.py:32-38</a></kbd>

`GET /api/staff/login?token=...` takes the shared STAFF_TOKEN as a query parameter. Under `opentelemetry-instrument`, the FastAPI/ASGI instrumentation records the request URL, query string included, as a span attribute. Uvicorn access logs also print the full path. So the staff secret gets exported to Dash0 and written to pod logs, and it also stays in browser history. The cookie then stores the raw shared token, not a session value derived from it. Accept the token in a POST body or header instead, and put an HMAC-signed session value in the cookie, not the token.

<details>
<summary>Send the token in a POST body so it never shows up in URLs.</summary>

````
class StaffLogin(BaseModel):
    token: str

@router.post("/api/staff/login")
def staff_login(body: StaffLogin, request: Request, response: Response):
    if not _valid(body.token):
````
