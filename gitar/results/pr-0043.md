<kbd>🟡 Medium risk</kbd> · Applying a NoExecute taint when a room closes could evict workloads from its talk Node and disrupt active sessions.

Turns room-state into Node taints and labels by patching `affinity.dev/full` and `affinity.dev/closed` taints and removing captions labels on talk Nodes each reconcile pass. Changes are requested before merge.

- Taint patch replaces the full `spec.taints` list, so unrelated taints such as cordon's `node.kubernetes.io/unschedulable` or lifecycle taints get stripped every 10s pass; only the owned `affinity.dev/full` and `affinity.dev/closed` keys should be added or removed in `backend/app/controller/rooms.py` and `backend/app/k8s/nodes.py`
- Span `k8s.node.taint` lacks the required `talkscout.` or `search.` prefix in `backend/app/controller/rooms.py`, so it won't match existing dashboards and alerts

<details>
<summary>⚠️ <b>Bug:</b> Taint patch overwrites every taint the controller doesn't own</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/43/files#diff-8de9d6dbeb9260aaee213d38197792ca1ed40e5127a85210882acf8298ec1943R76-R85">backend/app/controller/rooms.py:76-85</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/43/files#diff-83229201e279f93a3d622d2570ad4d0905a73b1db155b7a221f37a848646d715R20-R26">backend/app/k8s/nodes.py:20-26</a></kbd>

`reconcile_rooms` sends `spec.taints = desired_taints(...)`, which is just the KWOK taint plus full/closed. Node `spec.taints` has no merge key, so this patch replaces the whole list. Any other taint on a talk Node gets removed: `node.kubernetes.io/unschedulable` from `kubectl cordon`, the not-ready/unreachable taints the node lifecycle controller adds, or taints set by hand or by other tools. `taint_key(current) != taint_key(taints)` is then true whenever such a taint is present, so each 10s pass strips it again and the lifecycle controller adds it back. The result is a patch-and-span every pass and a cordoned Node that still accepts Pods. Fix: keep the taints whose keys aren't `affinity.dev/full`/`affinity.dev/closed`, and only add or remove the two owned keys.

<details>
<summary>Keep taints that are not owned and change only the affinity.dev ones</summary>

````
OWNED = {FULL_TAINT["key"], CLOSED_TAINT["key"]}

def desired_taints(status: str, current: list[dict]) -> list[dict]:
    taints = [t for t in current if t["key"] not in OWNED]
    if status == "full":
        taints.append(FULL_TAINT)
    if status == "closed":
        taints.append(CLOSED_TAINT)
    return taints
````
