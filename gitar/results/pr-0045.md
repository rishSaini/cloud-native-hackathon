Adds an editorial redesign for the phone screens with cream paper, Bodoni Moda and Instrument Serif type, and a full-browser laptop layout with a Contents sidebar and two-column spreads. Changes are requested because the laptop Contents sidebar shows on no-chrome Show and Staff screens, covering the full-screen content.

A second open issue: on the Now spread, the 'Make your card first' section lands alone in the narrow sticky right column instead of the break slot, and should target `breakSlot` directly.

<details>
<summary>⚠️ <b>Bug:</b> Laptop Contents sidebar reappears on no-chrome Show/Staff screens</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/45/files#diff-9869fe8a81507aaf5b3f4d639fd1200fddc85768c7563d148e06f3b9e1a9ea21R173-R180">frontend/static/css/editorial.css:173-180</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/45/files#diff-9869fe8a81507aaf5b3f4d639fd1200fddc85768c7563d148e06f3b9e1a9ea21R199">frontend/static/css/editorial.css:199</a></kbd>

`phone.css` hides navigation with `body.no-chrome .tabbar { display: none; }`, which has specificity (0,2,1). The new laptop rule `body:not(.on-sky) .tabbar { display: flex; … }` has the same specificity. Because `editorial.css` loads last, it wins. At widths of 64rem and up, the fixed 15rem Contents column therefore shows on `show.js` ("Show across the table") and `staff.js`, which both set `chrome: false` and are not sky screens. On those screens `.app-shell` gets no 15rem left margin (that rule is limited to `:not(.no-chrome)`), so the sidebar covers the left side of the full-screen content. The fix is to add `:not(.no-chrome)` to the laptop tabbar rules, as the `.app-shell` rule already does.

<details>
<summary>Limit the laptop tabbar layout to chrome screens</summary>

````
body:not(.on-sky):not(.no-chrome) .tabbar {
  top: 0; bottom: 0; right: auto;
  width: 15rem;
  display: flex; flex-direction: column; align-items: stretch; justify-content: flex-start;
  gap: 0;
  padding: 7.5rem 2rem 2rem;
  border-top: 0; border-right: 1px solid var(--ink);
}
````

</details>

</details>

<details>
<summary>💡 <b>Edge Case:</b> Now spread puts the 'Make your card first' card alone in column 2</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/45/files#diff-9869fe8a81507aaf5b3f4d639fd1200fddc85768c7563d148e06f3b9e1a9ea21R211-R213">frontend/static/css/editorial.css:211-213</a></kbd>

`.now > :last-child` moves the last child into the sticky right column. That is meant for `breakSlot`. When the user has no card, though, `now.js` appends a single "Make your card first" section to `.now`, and that section is the last child. On laptops it ends up in the narrower right column with nothing in the left column. The fix is to target the break slot directly, for example by giving `breakSlot` a class such as `now-aside` and selecting `.now > .now-aside`.

<details>
<summary>Target the break slot by class (and add class "now-aside" to breakSlot in now.js)</summary>

````
.now > .now-aside { grid-column: 2; grid-row: 1 / span 12; position: sticky; top: 9rem; }
````
