<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/47/files#diff-0b316b817268af918e37678a748eefb94320d9fdc7fecb67333a782fa5d8e424R21-R25">deploy/jobs/seed-demo-001.yaml:21-25</a></kbd> <kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/47/files#diff-275896068aa28536a4957dd26384e698fef14ade9dab8a2c3e3f1efa72dc5e43R13">scripts/seed_demo.py:13</a></kbd>

The Dockerfile only copies `scripts/ingest.py` into the image (`COPY scripts/ingest.py scripts/ingest.py`). `scripts/seed_demo.py` is never copied, so `seed-demo-001` runs `python scripts/seed_demo.py` in `/app` and exits right away with `can't open file '/app/scripts/seed_demo.py'`. Because `backoffLimit: 0`, the Job fails on the first attempt and seeds nobody. The docstring's claim that it "runs in the app image" is therefore false. Fix: add `COPY scripts/seed_demo.py scripts/seed_demo.py` to the Dockerfile.

<summary>⚠️ <b>Edge Case:</b> State file is written only at the end, so a failed run can't be reset</summary>

<kbd>📄 <a href="https://github.com/rishSaini/cloud-native-hackathon/pull/47/files#diff-275896068aa28536a4957dd26384e698fef14ade9dab8a2c3e3f1efa72dc5e43R85-R96">scripts/seed_demo.py:85-96</a></kbd>

`seed()` keeps the sessions in memory and writes `--state` only after every attendee is done. `urllib` raises `HTTPError` on any 4xx/5xx response, and it raises `URLError` or a timeout on network trouble. If that happens partway through, for example a 503 from `POST /api/attendees` or an app restart during rollout, the script exits and the attendees it already created are never saved. `--reset` then reports "nothing to reset", or it resets only an older run. Those synthetic cards, RSVPs and placement requests stay live, and nothing in the API ties them back to the script. A rerun also overwrites the state file instead of adding to it, so earlier seeded sessions are lost the same way. Fix: save the state after each attendee, or in a `try/finally`, and merge with any existing state file.

<details>
<summary>Persist incrementally and merge with existing state</summary>

````
path = Path(args.state)
state = json.loads(path.read_text()) if path.exists() else []
try:
    for person in people:
        c = Client(args.url, args.rate)
        me = c.call("POST", "/api/attendees")
        state.append({"attendeeId": me["attendeeId"], "session": c.session()})
        path.write_text(json.dumps(state, indent=1))
        card = {k: v for k, v in person.items() if k != "cluster"}
        c.call("PUT", "/api/card", card)
        c.call("POST", "/api/placements", {"slot": args.slot})
        c.call("POST", f"/api/breaks/{args.break_id}/rsvp", {"going": True})
finally:
    path.write_text(json.dumps(state, indent=1))
````
