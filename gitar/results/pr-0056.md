**Team cluster budget: within budget.** This PR only adds an env var, so resources are unchanged. Totals for everything in `deploy/kustomization.yaml`:

| | Total | Budget |
|---|---|---|
| CPU requests | 950m | 2 CPU |
| Memory requests | ~2.94 GiB | 4 GiB |
| CPU limits | 3700m | 4 CPU |
| Memory limits | ~4.25 GiB | 8 GiB |
| PVCs | 2 | 4 |
| Storage | 6 GiB | 20 GiB |

Breakdown (requests / limits):
- app (x2): 200m, 384Mi / 1000m, 1024Mi
- controller (x1): 100m, 192Mi / 500m, 512Mi
- elasticsearch (x1): 500m, 2Gi / 1500m, 2Gi, PVC 5Gi
- room-state-sweep CronJob (1 concurrent): 50m, 128Mi / 200m, 256Mi
- postgres (CNPG, 1 instance): 100m, 256Mi / 500m, 512Mi, PVC 1Gi

Every container has requests and limits. The one-off Jobs under `deploy/jobs/` aren't in the kustomization. If both ran at once, they would add 150m CPU and 256Mi memory in requests, and 750m CPU and 512Mi in limits, which still fits.
